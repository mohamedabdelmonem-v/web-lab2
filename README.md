# web-lab2
Create a single-page website using only HTML and CSS that demonstrates the desired styles.

## Overview
This project presents a single HTML document (`index.html`) that changes its visual appearance dynamically based on the linked CSS stylesheet (`styleA.css` or `styleB.css`).

## File Organization
- `index.html`: The core HTML structure containing six box elements.
- `styleA.css`: Implements a vertical Flexbox layout with alternating box colors, centered alignment, and a distinct final element style.
- `styleB.css`: Implements a horizontal layout preventing box wrapping, with dotted left borders, fixed positioning for the last element, and hover interaction effects.
- `README.md`: Documentation for the assignment.

## Challenges Faced
1. **Vertical Centering in Flexbox (Style A)**: Ensuring all 6 boxes remained centered horizontally and equally spaced vertically during window resizing without changing size or overlapping.
2. **Fixed Positioning & Non-wrapping (Style B)**: Preventing elements A through E from wrapping on smaller screens using `white-space: nowrap` while positioning the final box `F` fixed to the bottom right corner of the viewport.
